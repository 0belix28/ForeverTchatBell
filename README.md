## 🇫🇷 Français

### Présentation

**ForeverTchatBell** joue un son chaque fois que vous recevez un message dans le tchat, avec un son différent au choix pour chaque canal.

Par défaut, seul le canal **Guilde** est activé, avec le son de **cloche de l'hôtel des ventes**. Vous ne ratez plus un message de votre guilde, même en regardant ailleurs.

### Fonctionnalités

- 🔔 **Un son par canal**, chacun activable séparément :
  Guilde, Officiers, Chuchotements, Chuchotements Battle.net, Groupe, Raid, Avertissement de raid, Instance, Dire, Crier, Canaux (Commerce, Général…) et Communautés.
- 🎵 **Choix du son parmi tous les sons du jeu** grâce à [ForeverSoundLibrary](#addon-recommandé) : cliquez sur « Changer… », écoutez, validez.
- ▶️ Bouton **Écouter** pour tester le son d'un canal, et bouton **Défaut** pour remettre la cloche.
- 🙊 **Vos propres messages ne sonnent pas** (option pour les inclure quand même).
- ⏱️ **Délai anti-spam** réglable (2 s par défaut) : quand beaucoup de messages arrivent d'un coup, le son ne joue pas en boucle.
- 🔊 **Canal audio Master** au choix : le son s'entend même si les effets sonores du jeu sont coupés.
- ⚙️ **Panneau de configuration** intégré au menu du jeu : Échap › Options › AddOns › ForeverTchatBell.

### Installation

1. Téléchargez la dernière version.
2. Placez le dossier `ForeverTchatBell` dans `World of Warcraft\_forever_\Interface\AddOns\`
   (ou le dossier `Interface\AddOns` de votre version du jeu).
3. Relancez complètement le jeu et vérifiez que l'addon est coché dans la liste des AddOns.

### Addon recommandé

Le bouton **« Changer… »** utilise **ForeverSoundLibrary** (version 0.3.0 ou plus), une bibliothèque de tous les sons et musiques du jeu.
Sans lui, ForeverTchatBell fonctionne normalement avec la cloche de l'hôtel des ventes, mais le son ne peut pas être changé.

### Commandes

| Commande | Effet |
|---|---|
| `/ftb` | Ouvrir le panneau de configuration |
| `/ftb toggle` | Activer / désactiver tous les sons |
| `/ftb test` | Jouer le son de la guilde |
| `/ftb help` | Afficher l'aide dans le tchat |

`/tchatbell` fonctionne aussi. Le panneau s'ouvre également depuis le bouton des addons de la minicarte.

### Compatibilité

Conçu pour **WoW Forever** (interface 16001). Les réglages sont sauvegardés pour tout le compte.

## 🇬🇧 English

### Overview

**ForeverTchatBell** plays a sound every time you receive a chat message, with a different sound of your choice for each channel.

Out of the box, only the **Guild** channel is enabled, using the **Auction House bell** sound. You won't miss a guild message again, even when you're looking away.

### Features

- 🔔 **One sound per channel**, each one can be turned on or off:
  Guild, Officer, Whispers, Battle.net whispers, Party, Raid, Raid Warning, Instance, Say, Yell, Channels (Trade, General…) and Communities.
- 🎵 **Pick any sound from the game** with [ForeverSoundLibrary](#recommended-addon): click "Changer…" (Change), listen, confirm.
- ▶️ **Écouter** (Play) button to preview a channel's sound, and **Défaut** (Default) button to restore the bell.
- 🙊 **Your own messages stay silent** (optional setting to include them).
- ⏱️ Adjustable **anti-spam delay** (2 s by default): when many messages arrive at once, the sound doesn't loop endlessly.
- 🔊 Optional **Master audio channel**: you hear the sound even when the game's sound effects are muted.
- ⚙️ **Settings panel** built into the game menu: Esc › Options › AddOns › ForeverTchatBell.

> The in-game interface is currently in French.

### Installation

1. Download the latest release.
2. Put the `ForeverTchatBell` folder into `World of Warcraft\_forever_\Interface\AddOns\`
   (or the `Interface\AddOns` folder of your game version).
3. Fully restart the game and make sure the addon is enabled in the AddOns list.

### Recommended addon

The **"Changer…"** (Change) button uses **ForeverSoundLibrary** (version 0.3.0 or later), a browser for every sound and music track in the game.
Without it, ForeverTchatBell still works with the Auction House bell, but the sound can't be changed.

### Commands

| Command | Effect |
|---|---|
| `/ftb` | Open the settings panel |
| `/ftb toggle` | Turn all sounds on / off |
| `/ftb test` | Play the guild sound |
| `/ftb help` | Show help in the chat |

`/tchatbell` also works. The panel can also be opened from the minimap AddOns button.

### Compatibility

Made for **WoW Forever** (interface 16001). Settings are saved account-wide.
